Vendor Dashboard

1. Dashboard Overview
   Summary of vendor performance and activities:
   --cards
   • Total Sales
   • Total Orders
   • Pending Orders
   • Revenue Statistics
   --seperate component
   • Product Views
   --seperate component
   • Notifications
2. Products
3. All Products
   View and manage all listed products.
4. Add New Product
   Create and publish products with:
   • Product Name
   • Description
   • Images / Gallery
   • Category Selection
   • Base Price
   • SKU
5. Product Categories
   Assign products to relevant marketplace categories.
6. Product Attributes
   Create configurable attributes for products such as:
   • Size
   • Color
   • Length
   • Material
   • Weight
   • Capacity
   These attributes can be reused across multiple products.
7. Product Variations
   Create variations based on selected attributes.
   Example:
   • T-Shirt → Size (S, M, L, XL)
   • Shoes → Size + Color
   • Hair Extensions → Length + Color
   Each variation can have:
   • Unique SKU
   • Different price
   • Separate stock quantity
8. Inventory Management
   • Stock Quantity
   • Low Stock Alerts
   • Out of Stock Status
9. Product Status
   • Active
   • Draft
   • Pending Approval (if admin review is required)
10. Orders
    Manage all customer orders.
    • New Orders
    • Processing Orders
    • Completed Orders
    • Cancelled Orders
    • Returned Orders / Refund Requests
11. Messages
    Communication system between vendor and customers.
12. Reviews & Ratings
    • View customer reviews
    • Product ratings
    • Reply to reviews
13. Store Management
    Manage vendor storefront.
    • Store Profile
    • Store Logo & Banner
    • Store Description
    • Contact Information
    • Business Details
14. Promotions
    Marketing tools for vendors.
    • Create Discount Coupons
    • Promotional Campaigns
    • Featured Products
    8.Wallet
    Wallet Balance
    Multi-currency wallet depending on vendor location:
    Examples:
    • USD / NGN (Nigeria)
    • USD / ZAR (South Africa)
    Fund Wallet
    Vendors can add funds using payment gateways such as:
    • Paystack (Nigeria & Africa)
    • PayFast (South Africa)
    Wallet Functions
    • Deposit Funds
    • Transaction History
    • Payment for Subscriptions
    • Payment for Product Promotions
15. Subscription Plans
    Vendors must subscribe to access marketplace features.
    Subscription Features
    • Monthly / Yearly Plans
    • Product Listing Limits
    • Access to Premium Features
    • Priority Support
    Example Plans
    • Free Plan – Limited products
    • Standard Plan – More listings
    • Premium Plan – Unlimited listings + marketing tools
    Subscription fees can be paid from the vendor wallet.
16. Product Promotions (Boost Ads)
    Vendors can promote products for more visibility.
    Promotion Options
    • Boost Product – Appear at top of search results
    • Featured Products – Appear on homepage
    • Category Spotlight – Featured in category pages
    Promotion Duration
    • 3 days
    • 7 days
    • 14 days
    • 30 days
    Fees are automatically deducted from the vendor wallet.
17. Withdrawals / Payouts
    Vendor can request payout of earnings to:
    • Bank Account
    • Payment gateway account
    System shows:
    • Available balance
    • Pending balance
    • Withdrawal history
18. Analytics / Reports
    • Sales reports
    • Order statistics
    • Product performance
    • Promotion performance
19. Account Settings
    Profile Settings
    Update vendor details.
    Security Settings
    • Change password
    • Enable two-factor authentication
    Notification Settings
    Control email and system alerts.
